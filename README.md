## Описание

Программа реализует рекурсивный и итеративный двоичный поиск в отсортированном массиве целых чисел, а также хеш-таблицу с открытой адресацией и линейным пробированием. Ключи и значения имеют тип `int`.

## Реализованные возможности

- Двоичный поиск с обработкой граничных случаев.
- Собственная хеш-таблица с операциями insert, find и remove.
- Разрешение коллизий методом линейного пробирования.
- Обновление существующих ключей и повторное использование удалённых ячеек.
- Обработка отрицательных ключей, пустой и заполненной таблицы.
- Сравнение производительности для N = 1000, 10000 и 100000.
- Анализ временной и пространственной сложности.

## Среда разработки

- Язык программирования: C++17
- IDE: Microsoft Visual Studio

## Запуск

Скомпилировать файл `Lab8_Variant2_Year2.cpp` в режиме Release (x64). Программа автоматически выполняет тесты и измерения. Ручной ввод данных не требуется.

## Результат

Все 33 автоматических теста успешно пройдены. Сравнение выполнено на 10000 одинаковых для каждого метода запросах с долей успешных поисков 50%. Для каждого измерения используется медиана трёх запусков.
